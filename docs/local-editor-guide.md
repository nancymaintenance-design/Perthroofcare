# Perth Roof Care 本地后台

桌面双击“Perth Roof Care 本地后台”。启动时打开默认浏览器，后台隐藏运行；再次双击复用已启动的同站后台。电脑重启后再次双击即可。

1. 搜索并选择页面，点击预览正文或从“文字位置”选择正文、按钮、FAQ、图片说明和SEO字段。
2. 修改中文，点击“保存中文草稿”，等待保存成功；不改变生产英文或线上内容。
3. 切换桌面/手机、中文/English检查。英文是已批准原文，只读。
4. 错误修改可以从“已保存历史”选择修订并恢复；恢复生成新修订。
5. 改完在聊天告诉助手：“Perth Roof Care 草稿已保存，请同步英文，先本地预览，不部署。”确认后另行授权上线。

69个英文页面各有对应中文编辑，原版式及图片保留。原始评价、电话邮箱、注册事实、共享导航和页尾锁定。当前不提供新增页面、图片上传、链接目标修改或自动翻译发布。

草稿在source/.local-editor/drafts/，每页JSON包含修订号、基线hash及field变化；历史在history/，最近20条。草稿不进入Git和生产构建，清浏览器缓存不会删除。页面构建更新时基线变化会拒绝套旧草稿，请让助手人工合并，不要删除历史规避。

手动启动：在source运行 `npm run editor`，使用终端输出的地址，默认4206端口；占用时自动换后续端口，不停止别的服务。只允许本机127.0.0.1访问。关闭浏览器不会停止隐藏服务；启动日志在.local-editor/launcher/launcher.log。

助手可以通过后台workflow接口读取本次中文修改和原始英文；同步须绑定本页修订及baseHash，更新生成源及严格中文词典，不能仅修改public或盲目替换全站同名文字。后台本身不会执行Git、Vercel、在线模型或邮件。

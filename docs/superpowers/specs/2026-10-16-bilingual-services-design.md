# Perth Roof Care 中英双语设计

用户于 2026-10-16 确认全站 69 页双语方案，延续此前 Subagent-driven 执行方式。此范围是本地实现和验收，正式发布须有当次发布授权。

## 目标与语言路径

英语保留现有 69 个规范网址。简体中文在相同路径前增加 `/zh`，中文首页为 `/zh/`。英文导航在 Contact 后、主咨询按钮前加入可聚焦链接「中文服务」；中文导航同位置显示「English」。点击后进入当前页面的对应语言版本，保留查询参数和有效片段；不自动依据浏览器语言跳转、不新增语言偏好存储。中文页面中的站内页面链接指向中文版本。媒体、脚本、样式、电话、邮箱、外链和 `/api/enquiry` 不增加语言前缀。

## 全站内容

69 页一一对应，包括首页、服务目录、22 个服务/维修选项页、地区与郊区页、案例目录及记录、指南目录及文章、FAQ、About、Contact、隐私和法律页。保留现有章节、照片、阶段说明、锚点、品牌事实和服务能力。中文版翻译正文、标题、菜单、面包屑、按钮、图注、alt、可访问名称、表单标签/占位符、无 JavaScript 替代内容、元数据和结构化数据中的说明。品牌名称、电话、邮箱、ABN、ACN及正式英文邮寄地址可保持原文。

自然简体中文用词：roof/tile roof 为屋面/瓦屋面，roof tiles 为屋面瓦片，flashing 为泛水板，valley 为天沟，ridge capping 为屋脊盖瓦（涉及金属屋面时为屋脊盖板），repointing 为重新勾缝，rebedding 为重新铺设座浆，gutter 为檐沟，box gutter 为箱型檐沟，downpipe 为落水管。地名保持可识别名称，Perth 可译为珀斯，WA 是西澳大利亚州。标题直接说明服务和内容；不增加软文口号、空白区块或分散章节。

原文事实、施工阶段、资质边界、收费及隐私含义须准确表达。翻译不增加资质、保险、保修、报价、免费检查或已完工承诺；不恢复刚移除的通用检查收费提示。

## 静态生成和维护

在既有英文页面所有内容优化完成后、图片优化和发布复制之前，运行独立双语生成模块。从最终英文 DOM 提取需翻译的文本、属性、元数据及 JSON 数据的可读字段。使用规范化原文的稳定散列键查找人工中文译文，不请求第三方翻译服务。未知原文必须明确报错；译文缺失不得静默发布英文回退。翻译数据按有限大小文件组织；提取工具仅写本项目的工作资料目录。

英文生成仍为原有唯一内容源；中文页由构建派生。反复构建不得重复添加 `/zh/zh/`、语言链接或页面。发布流程从规范英文路由清单派生两种语言并打包全部 138 页。现有图片、路由专用样式、CSS 指纹、缓存及 Vercel API 输出保持可用。单独明确 404 页的中文与返回路径，任何声明的语言页均不得缺失。

## 双语 SEO 与数据

英语 HTML lang 为 `en-AU`，中文为 `zh-Hans`。每页自指 canonical；两种语言在 HTML head 中声明同一对 `en-AU`、`zh-Hans` 以及指向对应英文页的 `x-default`。hreflang 在 HTML 中维护，sitemap 仅列全部规范页面，避免重复机制。中文页的标题、description、Open Graph/Twitter 可读字段和 JSON-LD 可读字段使用中文，URL及页面实体 ID 按实际语言页生成；真实公司实体 ID 可保持共用。Article/FAQ/Service 可读内容与中文 DOM 一致。文章日期保留真实原日期，翻译不改写施工日期。

中文资讯和案例订阅数据在有对应页面时使用中文标题、摘要、内容和中文链接；中文页的订阅入口不得指向虚假的中文文件。资产 URL 保持共用，robots 可抓取两种语言，llms.txt 说明中文入口。Analytics 按实际页面路径记录，不改变账户或发送接口。

## 表单与交互

保持原必填字段、隐私同意、API、收件邮箱、校验和发送逻辑。中文页的必填/邮箱/隐私错误、发送中、成功、网络失败、服务端错误及预览不可发送提示均使用中文。错误不清空已填写内容；发送成功后恢复按钮及表单状态，保持现有可访问实时提示。可以输入中文姓名和咨询。既有菜单的触屏、键盘、Escape、焦点恢复行为在两种语言下一致。

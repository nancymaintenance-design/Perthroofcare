THE ROOF AS A SYSTEM

INFORMATION ORGANISED BY VISIBLE DETAILS.

Roof repair conversations are clearer when they begin with the part of the building that has changed. A tile edge, a metal sheet, a ridge line, a flashing junction or a drainage run each offers a distinct starting point.

Ellis Services Group uses this Perth roof repairs reading room to make the first step less opaque. It helps frame a useful enquiry around what is visible, where it is located and which material is involved.
